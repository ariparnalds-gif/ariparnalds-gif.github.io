DATA & ACCOUNT ACCESS

Privacy policy

Effective 10 October 2026

Iceland Trail Demand is a personal and internal research tool operated by Ari Arnalds. This policy describes the tracker and its public information website.

Google data the tracker accesses

The tracker retrieves aggregate Google Ads Keyword Planner information for selected keywords and countries: monthly search-volume estimates, competition indicators, bid ranges, and related keyword ideas. These statistics do not identify individual people who searched.

The private configuration includes Google Ads customer and manager account identifiers, an API developer token, an OAuth client ID and client secret, and an OAuth refresh token once the owner authorizes access. The Google Ads OAuth scope can permit both viewing and managing Ads data. The implemented tracker requests keyword research information and does not create ads or modify campaigns.

How the information is used

The information is used to research demand for Iceland hiking and trail-running routes and travel experiences, compare countries and seasons, retain a research history, and produce an internal dashboard. Google account information and credentials are used to authenticate those requests and refresh access for scheduled collection.

Google API data is not sold, provided to data brokers, used for personalized advertising, or used to train general-purpose artificial intelligence or machine-learning models. The tool does not use Google data for purposes unrelated to the disclosed research functions.

Storage and access

In the local setup, credentials are stored in the owner’s private configuration file, excluded from version control. Keyword estimates, report history, and run information are stored in local files. The owner controls access to these files and is responsible for protecting the computer and backups.

If the tracker is later configured to run through GitHub Actions, credentials must be kept in repository Actions secrets and research files in an appropriately restricted repository. Such a deployment uses GitHub to process and store the material needed to run the collection. This public website and its public repository contain no OAuth credentials, account identifiers, or private tracker reports.

Sharing and service providers

Google receives the authentication and keyword queries needed to provide the Google Ads API service. GitHub hosts this information website and, if configured separately, may host the tracker’s scheduled runs. Google and GitHub process information under their own applicable policies. The tracker does not intentionally share Google account information or research reports with other third parties.

Retention and deletion

The tracker keeps keyword history until the owner deletes the stored files. Credentials are retained while needed for authorized collection. To stop collection, disable its scheduled job and remove its credentials. Deleting local or repository files does not automatically delete copies in backups or Git history; those copies must be handled separately.

Revoking Google access

The owner can revoke the application’s access in Google Account permissions. After access is revoked, further API collection requires a new authorization. Previously collected reports remain until deleted.

Website visitors

This website has no visitor accounts, contact forms, analytics scripts, tracking pixels, or application cookies. Its hosting provider, GitHub, may process technical request information such as IP addresses and browser details to deliver and secure the website. See the GitHub General Privacy Statement. Using an email contact link opens the visitor’s chosen email application.

Policy updates and contact

Updates will appear on this page with a new effective date. Any material new use of Google user data requires an updated disclosure and appropriate consent before that use begins.

For questions about privacy, access, or deletion, contact Ari Arnalds at ariparnalds@gmail.com.
