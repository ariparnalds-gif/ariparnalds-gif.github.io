# Iceland Trail Demand information website

Public homepage, privacy policy, and terms for Ari Arnalds's personal Iceland hiking and trail-running demand research tool.

This repository contains only the static information website. It contains no tracker code, OAuth credentials, Google Ads account identifiers, or research reports.

## Pages

- `index.html` — application homepage
- `privacy.html` — privacy policy
- `terms.html` — terms of use
- `styles.css` — shared styling

## Publication

Publish the root of the `main` branch through GitHub Pages. The intended user-site repository is `ariparnalds-gif.github.io`, serving `https://ariparnalds-gif.github.io/`.

Google Search Console ownership verification must be completed with the OAuth project's owner account. Keep Google's verification HTML file or meta tag in this site after verification so ownership remains valid.

After the website and ownership are verified, configure the OAuth app's homepage, privacy policy, terms links, and authorized domain with the exact published URLs. Publication of this website alone does not guarantee Google OAuth branding approval.
