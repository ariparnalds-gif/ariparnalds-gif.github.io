FOLLOWING THE PATTERNS

THE TOOL

Search patterns,
over time.

Iceland Trail Demand is operated by Ari Arnalds for personal and internal research. It uses the Google Ads API to retrieve Keyword Planner estimates for selected hiking and running keywords.

The tracker compares countries, seasonal changes, and interest in guided trips, private trips, group experiences, and route information. Its reports contain aggregate keyword statistics, not information about individual searchers.

WHAT IT DOES

01

Collects keyword estimates

Monthly search volumes, competition, and bid ranges for selected keywords and countries.

02

Keeps a research history

A weekly collection records new estimates and revisions so patterns can be compared over time.

03

Uses the owner’s authorization

The owner connects an authorized Google Ads account through a one-time Google OAuth consent flow. This website does not offer visitor sign-in.

About Google
account access.

The Google Ads OAuth permission can allow viewing and managing Ads data. This tracker’s implemented API calls request keyword metrics and ideas; they do not create campaigns or change advertising budgets.

OAuth credentials are kept with the private tracker configuration. This public website contains only information about the application.

See the privacy policy for data handling, storage, and revoking access. Questions can be sent to ariparnalds@gmail.com.
